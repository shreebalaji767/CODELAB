🧠 Memory & References

The browser owns the real heap and garbage collector, so we teach observable reference behavior rather than drawing fake RAM diagrams and calling them reality.

Reference identity

const a = {x: 1};
const b = a;
b.x = 99;
console.log(a.x); // 99

Garbage collection

JavaScript engines decide when unreachable objects are collected. You cannot demand “collect now” from ordinary browser JavaScript. We therefore separate observable reference behavior from implementation-dependent GC behavior.

Engineer rule: if your explanation requires knowing the exact GC moment, stop pretending. Measure what is observable and use documentation for engine internals.
