# Code Lab for Render

Languages: HTML, CSS, JavaScript, Python, SQL, C.

## Deploy
1. Upload this folder to GitHub.
2. Render -> New Web Service -> connect repository.
3. Choose Docker (Dockerfile is included).
4. Deploy.

## Important
This starter executes submitted code on the server. It has basic timeout/output limits but is NOT a hardened public multi-tenant sandbox. Do not expose it to arbitrary public users without stronger isolation (containers/VMs, network restrictions, CPU/memory limits, filesystem restrictions, and rate limiting).
